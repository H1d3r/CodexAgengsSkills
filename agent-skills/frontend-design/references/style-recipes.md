# 有界风格配方

这些是原创选项，不是厂商模板。已有设计系统优先；只修交互或逻辑时不选新风格。选择受众、内容、任务与授权支撑的一种主方向，局部借用另一种；不要把选项变成固定品牌承诺。

| 方向 | 适合内容 | 可调整手段 | 边界 |
|---|---|---|---|
| 编辑型清晰 | 文章、产品说明、研究结果 | 大小标题对比、充足行距、窄正文、真实图文节奏 | 不为“高级感”牺牲阅读；不用大图掩盖主内容 |
| 精密工具型 | 管理后台、数据操作、复杂表单 | 紧凑但可点的密度、对齐、分隔线、稳定状态、数字列对齐 | 不强制卡片化；保持表格信息与批量操作可达 |
| 克制品牌表达 | 明确授权的产品/活动落地页 | 一种主强调色、现有品牌字体/素材、有限几何形状 | 不模仿厂商品牌；不默认渐变、视差、玻璃或伪造社会证明 |
| 舒适阅读型 | 帮助中心、社区、长时间阅读 | 柔和表面、可区分层级、少量圆角、阅读行宽 | 低刺激不等于低对比；状态仍用语义文字/图标 |

## 参数决策

- **内容密度**：舒适/标准/紧凑由任务频率与输入设备决定；减少留白时不压缩关键点击区域，窄屏允许重排。
- **排版**：优先项目/系统字体；少量层级建立秩序，不能把辅助信息缩成难读小字。无授权不加载外部字体或素材。
- **色彩**：以中性底色建立信息秩序，强调色服务动作和品牌；成功/警告/错误由语义角色承载，装饰色不能兼任唯一状态提示。
- **形状与深度**：用间距、边界或层级解决分组后，再选择圆角/阴影；不叠加高密度阴影和半透明层造成噪声。
- **动效**：一次操作对应少量必要反馈；用 token 控制时间和位移，reduced motion 下不依赖位移传达含义。
- **主题**：深色主题重选表面与前景角色，不反转图片；用户显式主题选择优先于系统偏好。

## 输出最小设计说明

说明“主要用户任务 → 选中方向 → 本次改变的排版/密度/强调色 → 保留的项目事实 → 验证状态”。不强制额外生成设计报告或重做无关页面。

实践依据及访问日期见 [设计系统参考](design-system.md)；配方名称与参数不是官方标准，也不是对任一品牌的复刻。
